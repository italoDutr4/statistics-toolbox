# 🧰 Statistics Toolbox

Welcome to the **Statistics Toolbox**! 

This repository is a growing library of scripts, functions, and base templates for different types of statistical analyses. The goal here is to have a centralized place to find that analysis code you know you've written but can't remember where you saved, and to make this foundation available to anyone who needs it.

## 🎯 Goals
- **Streamline workflows:** Ready-to-use scripts to copy, paste, adapt to your data, and run.
- **Reproducibility:** Ensure standard analyses are performed consistently.
- **Sharing:** Help other researchers and data analysts implement statistical tests correctly.


## 🚀 How to use
1. Open the corresponding script.
3. At the beginning of each script, you will find a comment block explaining:
   - What the analysis is for.
   - Required packages.
   - The expected data format (e.g., *long* or *wide* format).
4. Replace the example dataset with your data and run the code!
